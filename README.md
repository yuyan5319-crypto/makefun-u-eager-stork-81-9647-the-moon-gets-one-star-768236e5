A one-star review of the Moon, 110 characters, built on the one grievance only the Moon can offer: tidal locking. After 4.5 billion years together it still only shows us one face — no craters joke, no cheese joke, no brightness joke, just a relationship complaint with a receipt.

> ★☆☆☆☆ The Moon only shows me one face after 4.5 billion years. Either it's hiding something or it's just rude.

## Run it

```sh
node main.ts
```

This writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it to stdout. The program validates the line before writing: it must be 1–120 characters, not only whitespace, must name the Moon, and must carry its one-star rating — if any check fails, it refuses to run.
